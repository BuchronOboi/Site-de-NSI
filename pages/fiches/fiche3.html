Fiche 3.1 - Consignes et premiers pas

Le langage de programmation

Définition : un langage de programmation est un langage compréhensible par la machine qui l'exécute. Il existe plusieurs langages de programmations tels que le C, le C++, le java, le php etc... En NSI nous utilisons Python comme langage de programmation car il est simple et utilisé dans l'enseignement supérieur.
Pour manier python, il existe de nombreux logiciels (comment Geany ou VSCode mentionnés ci-dessus), mais il existe des alternatives en ligne comme BASTHON ou CAPYTALE.

Vocabulaire

  • Script Python : texte d'un programme Python
  • Interpréteur Python : application qui interprète le langade Pytho, et le traduit dans un langage compréhensible par la machine (langage machine). Il peut être enrichi par de très nombreux modules notamment scientifiques. Ces modules sont des bibliothèques apportant des fonctionnalités déjà programmées, ce qui permet d'alléger le développement.
  • Console Python ou Shell : vous permet d'interragir avec l'interpréteur Python ou d'exécuter des scripts Python. Les trois chevrons ">>>" indiquent que l'interpréteur est prêt à recevoir des instructions.
  • IDE : logiciel de création d'applications, qui rassemble des outils de dévelommement fréquemment utilisés dans une interface utilisateur graphique (GUI). L'IDE utilisé au lycée est Pyzo.
  • Éditeur de texte : logiciel destiné à l'édition des fichiers textes. Par fichier texte, il faut comprendre l'ensemble des fichiers écrits, soit pour donner des informations à l'utilisateur, soit avec un ensemble d'instructions à fournir au système d'exploitation. Au lycée nous utilisons Geany.
    • Fiche 3.2 - Les variables

    I- Les variables

    Définition : une variable est une voite dans laquelle on stocke une information. Il existe plusieurs types de variables en fonction de la valeur qu'on rentre (int pour un nombre entier, float pour un nombre à virgule, bool pour un nombre binaire, str pour une chaine de caractères...). Python reconnaît le type de variable lors de l'affectation - on parle alors de typage dynamique.

    1- Les nombres

    Les nombres entiers tels que 1, 0, -8 ou 96 sont des nombres entiers sans virgule. Ils sont stockés dans des variables de type int (pour interer qui signifie entier en anglais).
    Les nombres à virgule comme 5.0, -2.4, 5e6 ou 5E3 sont de type float.
    Attention ! En python, les nombres à virgule s'écrivent avec un point . et non avec une virgule ,
    Le nombre 5 est de type int mais le nombre 5.0 est de type float.

    2- Les chaînes de caractères

    Une chaîne de caractères est une suite de caractères. En python, elle se nomme str (pour string qui signifie "chaîne de caractères" en anglais).
    Une chaîne de caractères est idenfitiable par ses guillemets simples '...' ou des guillemets doubles "...".
    Il ne fait pas confondre 3 qui est de type int, avec "3" qui est une chaîne de caractères.
    Si une chaîne de caractères contient déjà des guillemets, on l'entoure d'apostrophes. Exemple : 'Une robe "vraiment" !'
    La chaîne " " n'est pas vide : elle contient un espace, qui est considéré comme un caractère.

    II- Les noms que l'on ne peut pas donner aux variables

    Les variables ne peuvent :
  • pas contenir d'espace dans leur nom. Pour imiter l'espace on met le caractère _
  • pas comporter d'accents ou de caractères spéciaux.
  • pas contenir dans leur nom des commandes qui sont utilisées par python (exemple: print, input, for etc...)
  • pas commencer par une majuscule ni par un _

    Fiche 3.3 - Conditions et boucles
    Les instrucitons conditionnelles En programmation et dans la vie de tous les jours, il est crucial de faire des comparaisons. Exemple : si il fait beau, alors je sors dehors. Les conditions en Python fonctionnent exactement pareil.
    Pour faire une comparaison, on peut utiliser if, elif (ou else if) et else. Le code se présente comme ça :

    1 if (condition_vraie):
    2     instructions_a_realiser
    3 elif (condition_vraie):
    4     instructions_a_realiser
    5 else:
    6     instructions_a_realiser
  • if revient à dire en français "si la condition ci-dessous est vraie"
  • les : signifient "alors"
  • elif revient à dire "sinon si la condition ci-dessous est vraie"
  • quand else est présent, il est placé forcément à la fin des conditions; c'est les instructions qu'on exécute quand aucune des conditions n'est validée.
    • Les boucles Les boucles permettent de répéter plusieurs fois des instructions et permettent de remlpacer le copier/coller. En Python, il existe deux grand types de boucles. La boucle for et la boucle while.

    1- La boucle for

    La boucle for est utilisée quand on sait combien de fois celle-ci doit s'exécuter. Elle se code comme ça :
    1 for i in range(5): // i est la variable du compteur qui augmente de jusqu'à 5 exclu.
    2     instructions

    2- La boucle while

    La boucle while est utilisée quand on ne sait pas combien de fois elle doit s'exécuter.
    1 i = 10: // il faut initialiser la variable de la boucle.
    2 while i < 10: // la boucle while est exécutée tant que i est inférieur à 10
    3     instructions

    Les modules Les modules permettent d'ajouter des fonctions à Python. Il en existe un très grand nombre qui permettent de faire des choses très variées. Voici quelques modules principaux :
  • Le module math permet d'implémanter de nombreuses opérations mathématique à Python (les racines carrées avec sqrt(), la valeur absolue avec abs(), sin(), cos(), tan() pour la trigonométrie et bien d'autres).
  • Le module random qui renvoie un entier aléatoire situé entre a et b avec l'instruction randint(a, b).
  • Le module turtle qui permet de tracer des formes avec des couleurs.
  • Et bien d'autres...

    • Pour importer un module, il faut mettre une de ces trois inscructions tout en haut du code Python :
    from math import* // Importe toutes les fonctions dans le module math

    import math // Importe aussi toutes le fonctions dans le module math

    from math import sqrt, sin // Importe seulement les fonctions du module qui sont marquées après le import (ici la fonction sqrt et la fonction sin)
    Créer et utiliser les fonctions

    I- Créer une fonction

    Les fonctions permettent de réutiliser du code pour éviter les répétitions et ainsi mieux organiser le programme. Une fonction est définie, puis elle peut être appelée à tout moment dans le programme. Un fontion se définit comme ceci :
    1 def nom_de_la_fonction(arguments): // les arguments doivent être placés dans les parenthèses, mais ne sont pas obligatoires. Attention à ne pas oublier les :
    2    instructions exécutées par la fonction
    3    return variable_a_retourner // Un return permet de renvoyer une variable à l'issue de la fonction.

    II- Utiliser une fonction

    Comment appeler une fonction ?
    1 def bonsoir(): // Définition d'une fonction qui ne prend pas d'arguments. On met quand même les parenthèses
    2    return "Bonsoir les filles."
    3
    4 print(bonsoir()) // On veut afficher la fonction : il faut marquer le nom de la fonction (bonsoir) avec les parenthèses

    >>> Bonsoir les filles. // Voilà le résultat

    III- Les fonctions lambda

    Les fonctions lambda, qu'est-ce que c'est ?
    Elles permettent de définir une fonction simple en une seule ligne. Exemple :
    (lambda a, b : a*b)(2, 3)
  • a et b sont des paramètres de la fonction
  • ce qui est après les : correspond à la valeur de retour de la fonction
  • (2, 3) correspond aux valeurs respectives de a et de b.

    • IV- Documenter une fonction

    Pour documenter une fonction, on place trois guillemets avant et après un court texte qui décrit la fonction.
    1 def nombre_plus_un(nombre_de_depart):
    2    """Cette fonction ajoute 1 au nombre rentré"""
    3    return nombre_de_depart + 1
    4
    5 help(nombre_plus_un()) // on marque help avec le nom de la fonction entre parenthèses.

    >>> Cette fonction ajoute 1 au nombre rentré
