Geany , le logiciel utilisé pour éditer les fichiers html et css du site.
Après avoir téléchargé le site de Tom et installé Geany, nous pouvons découvrir le site Web en lançant le fichier index.html sur un navigateur. Nous arrivons sur cette page :



Nous pouvons également lancer ce fichier dans Geany pour voir le code de la page web.
Mais ce n'est pas tout, le site de Tom possède plusieurs sous-dossiers contenants eux aussi d'autres fichiers :

  • Le dossier images contient toutes les images du site.

  • Le dossier pages contient les differentes pages web du site (fichiers html).

  • Le dossier styles contient un fichier .css qui regroupe tous les éléments nécessaires à la mise en forme du site (couleurs, animations, placements...).
