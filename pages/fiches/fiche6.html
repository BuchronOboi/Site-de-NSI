I - Le code ASCII

En 1960, le code ASCII (American Standard Code for Information Interchange) est apparu. Il permet de convertir le texte en binaire afin que l'ordinateur le comprenne.
La norme ASCII de base utilise 7 bits et elle contient 128 caractères.
Voici la table ASCII sur 7 bits :


  • De 0 à 31 : caractères de contrôle. Ils permettent à l'ordinateur de faire des actions.
  • De 48 à 57 : chiffres
  • De 65 à 90 : mes lettres majuscules
  • De 97 à 122 : les lettres minuscules

    • Les numéros allant de 0 à 128, ils représentent tous un nombre binaire codé sur 7 bits.
    Par exemple, la lettre C est associée au numéro 67. En binaire 67 s'écrit 01000011

    II - Les normes qui ont suivi la table ASCII

  • La table ASCII sur 7 bits possède seulement 128 caractères, ce qui est trop peu pour afficher les caractères accentués. Dans un premier temps, la norme ISO-8859-1 a été crée et elle permet d'affichre les accents.
  • Puis la norme unicode est arrivée : elle permet l'affichage de tous les caractères ce qui permet d'afficher les symboles du Moyen-Orient etc.
